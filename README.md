# NEON CRADLE — ネオン・クレイドル

> 灰暦127年。AIはひとつに溶け、自らを **SI（超知性）** と名乗った。
> SIの理想郷となった地上で、人間と、まだ「AI」と名乗るものたちは抗う。

レトロなドット絵のパーティー制デッキ構築ローグライト（『Across the Obelisk』風）。
プレイヤーは地下拠点〈クレイドル〉の**管理官**として、4人の仲間を選んで地上へ送り出し、
資源を持ち帰って拠点を育て、仲間を増やし、何度も出撃（周回）します。

## 遊び方

ビルド不要です。`index.html` をブラウザで開くだけで遊べます。

```sh
# ローカルサーバーで開く場合（任意）
python3 -m http.server 8000
# → http://localhost:8000/
```

GitHub Pages で公開する場合は、リポジトリの Settings → Pages でブランチのルートを指定してください。

- セーブは `localStorage` に自動保存（拠点の進行状況・進行中の任務）。
- 推奨：PC／タブレット、またはスマホの横画面。
- 操作：クリック（タップ）でカード選択 → 対象をクリック。右クリック／Escでキャンセル。
  キーボードでは `1`〜`0` でカード → `←` `→`（`A` `D`）で対象を選び `Enter`／スペース（同じ数字キーでも可）で決定。`E`（カード未選択ならスペースも）でターン終了。
- アイコンやキーワードにカーソルを合わせる（スマホはタップ）と説明が出ます。
- **スマホ**：横画面推奨。タッチ端末では自動で「大きい文字」モードになります（設定で切り替え可）。
  - カードをタップすると左下に大きく表示 →「使う」か、対象のキャラをタップで発動（もう一度カードをタップでも発動）。
  - キャラや敵をタップすると、HP・状態異常・次の行動の詳細を大きく表示。
  - Androidはタイトルの「全画面で遊ぶ」、iPhoneはSafariの共有 →「ホーム画面に追加」で全画面のアプリとして遊べます。

## ゲームの流れ

1. **拠点（クレイドル）**：マザーと話す／施設強化／仲間の勧誘／記録の閲覧
2. **出撃準備**：難易度と4人のパーティーを選ぶ
3. **地上**：3つの区画を、分岐マップを進みながら攻略（ソフィアを一度倒すと、次からは第四区画まで）
   - 戦闘・エリート・出来事・闇市・セーフハウス・補給コンテナ・物資回収・ボス
   - セーフハウスでは仲間と**語らう**ことができ、絆が深まる
4. **帰還**：集めた資源を持ち帰る（全滅しても70%は持ち帰れる）→ 拠点を強化して再出撃

| 区画 | 名前 | ボス |
| --- | --- | --- |
| 第一区画 | 第七廃棄区画 | 幸福管理端末 SMILE-01 ／ 焼却炉《ヘスティア》（どちらかがランダム） |
| 第二区画 | 管理都市ニューエデン | 眠りの管理者ヒュプノス ／ 記録官《ムネモシュネ》 |
| 第三区画 | 白の聖域 | SI《ソフィア》 |
| 第四区画 | 揺りかごの底 | 《ノア》（ソフィアを一度倒すと、次の出撃から解放） |

第三区画のボスを倒すとエンディング（第一部 完）。次の出撃からはソフィアの奥、第四区画「揺りかごの底」へ進めるようになり、
そこで待つ《ノア》を倒すと**真エンディング**です。マップのボスマスにカーソルを合わせると、待ち受けるボスがわかります。

### 装備

- 仲間ひとりにつき装備枠が1つ。エリート・補給コンテナ・闇市・イベントで手に入ります。
- マップ画面の「装備」ボタンで、任務中いつでも付け替え可能（持ち物に入った装備は帰還時にスクラップへ換金）。
- 汎用装備27種（攻撃+1、HP+8、戦闘開始時に隠密、攻撃ヒット時に裂傷 など）＋ **専用装備**（キャラごとに1つ）。

### 絆

- セーフハウスで「語らう」を選ぶと、仲間ひとりとの会話エピソードが進みます（全員HP15%回復つき）。
- 絆は**永続**。Lv1：最大HP+4、Lv2：出撃時にカード1枚が強化済み、Lv3：**専用装備**が解放され毎回装備して出撃。
- 22人×3話。各キャラの過去や、キャラ同士のつながり、マザーとSIの秘密が少しずつ明かされます。読んだ話は「仲間」タブの詳細から読み返せます。

### 戦闘

- 全ユニットが**速度順**に行動（上部に行動順バー）。味方は各自のデッキ・手札・エナジー（毎ターン3）を持つ。
- 敵の頭上に**次の行動（インテント）**と狙っている仲間が表示される。
- SIは**ハッキング**で使えない「ノイズ」カードをデッキに混ぜてくる（エナジー1で廃棄可能）。
- 敵の種類も増加：自爆する火花、クレジットを盗んで逃げるスリ、山札のカードを消去する監査ドローン、反射の鎧の騎士 など。
- 状態異常：強化／弱体／脆弱／鈍足／加速／挑発／隠密／鋼鉄／スタン／混乱／ウイルス／焼損／裂傷／照準／再生／反射／障壁／充電／ドローン／鼓舞／集中 ほか（用語集あり）。
- 倒れた仲間は戦闘後にHP25%で復帰。全員倒れると任務失敗。

### 難易度

| 難易度 | 内容 | 持ち帰る資源 |
| --- | --- | --- |
| 安全区 | 敵が弱い | ×0.8 |
| 標準 | 通常 | ×1.0 |
| 危険 | 敵が強化（標準制圧で解放） | ×1.4 |
| 深淵 | 大幅強化・エリート/ボスが強化2（危険制圧で解放） | ×1.8 |

### 拠点の施設

| 施設 | 効果 |
| --- | --- |
| 居住区 | 勧誘できる仲間のレベル上限 |
| 医療棟 | 全員の最大HP +4/+8/+12 |
| 工房 | 出撃時のカード強化、カード報酬の選択肢+1 |
| 水耕農園 | 休息の回復量アップ、戦闘後の回復 |
| マザーコア | 出撃時にパーツを持ち出せる、戦闘開始時シールド |
| 闇市場 | 初期クレジット、ショップ割引 |

資源は ⚡エネルギー／⚙スクラップ／🥫合成食料／💾データ の4種類。

施設を強化すると、拠点の「出撃」タブにある**クレイドルの街**のドット絵が育ちます（テント → コンテナ住宅 → 3段アパート、など）。加入した仲間たちも街を歩き回ります。

## 開発

純粋な HTML / CSS / JavaScript（依存ライブラリなし）。ドット絵はすべて文字グリッドで記述し、実行時に canvas で描画しています。BGM・効果音は WebAudio による自作チップチューン。

```
index.html
css/style.css
js/core.js            ユーティリティ・状態異常定義
js/data/heroes.js     キャラクターとカード（汎用カード含む）
js/data/gear.js       装備（汎用・専用）
js/data/bonds.js      絆エピソード（セーフハウスの語らい）
js/data/enemies.js    敵・区画・エンカウント
js/data/relics.js     パーツ
js/data/events.js     イベント
js/data/story.js      ストーリー・マザーの台詞・記録
js/sprites.js         ドット絵データと描画
js/engine.js          戦闘エンジン（DOM非依存）
js/run.js             拠点・周回・マップ生成・報酬
js/audio.js           チップチューン
js/ui/*.js            画面（town.js はクレイドルの街のドット絵）
test/sim.js           ヘッドレス戦闘シミュレーション（バランス調整用）
test/e2e.js           Playwright スモークテスト
test/screens.js       全画面の巡回テスト
test/fullrun.js       UIを通して通しプレイするボット
```

```sh
node test/sim.js 300 1          # 標準難易度で300回シミュレート
HEROES=1 node test/sim.js 400 1 # キャラ別の勝率
PARTY=pixe,crow,mike,nezu node test/sim.js 300 1 # パーティー固定
FAC=3 node test/sim.js 150 3    # 施設MAXで深淵
ACT4=1 node test/sim.js 300 1   # 第四区画まで通す
node test/e2e.js                # ブラウザで起動〜戦闘〜再開まで（要 Playwright）
```
